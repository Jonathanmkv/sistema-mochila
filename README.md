# 🎒 Sistema de Inventário (Mochila Free Fire) em C

Um sistema de gerenciamento de inventário inspirado na mecânica de mochila do jogo **Free Fire**, desenvolvido em **C** para execução via terminal. 

O objetivo principal deste projeto acadêmico é aplicar na prática conceitos fundamentais de **Estrutura de Dados**, implementando operações de manipulação de itens e algoritmos clássicos de **ordenação e busca**.

---

## 📌 Funcionalidades

- **Gerenciamento de Itens (CRUD):** Adição, remoção, exclusão e listagem detalhada dos itens armazenados na mochila.
- **Algoritmos de Ordenação:** Organização dinâmica do inventário utilizando diferentes métodos clássicos:
  - *Bubble Sort*
  - *Selection Sort*
  - *Insertion Sort*
- **Sistema de Busca:** Localização rápida de itens específicos dentro da estrutura de dados da mochila.
- **Controle de Capacidade:** Validação de espaço e organização dos recursos coletados pelo jogador.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **Linguagem:** C (C99)
- **Estruturas de Dados:** `structs`, vetores/arrays e manipulação de ponteiros.
- **Algoritmos:** Ordenação (*Bubble*, *Selection*, *Insertion Sort*) e algoritmos de busca.
- **Compilador Recomendado:** GCC / Clang / MSVC
